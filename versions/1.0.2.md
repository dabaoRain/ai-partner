# V1.0.2 稳定聊天链路

> 对应 [`plan.md`](../plan.md) P0「稳定聊天链路」  
> 能力：停止生成、超时、幂等、防重复提交、断流错误码、可重试策略

## 行为约定

| 能力 | 约定 |
| --- | --- |
| 停止生成 | 前端 Abort + `POST /chat/stop`；服务端中断上游流，已有片段可落库 |
| 超时 | 首字超时 / 整段超时，配置见 `config.py` |
| 幂等 | 必填 `client_request_id`；已完成则回放；进行中重复提交 409 |
| 防重复 | 同一会话同时仅允许一条进行中的生成；前端发送中禁用再次发送 |
| 错误码 | SSE `error.code` + `retryable`；HTTP 409 用于冲突 |
| 重试 | `retryable=true` 时前端展示重试；失败态可用新 `client_request_id` 再发 |

## SSE 错误码

| code | retryable | 说明 |
| --- | --- | --- |
| `FIRST_TOKEN_TIMEOUT` | true | 首字超时 |
| `STREAM_TIMEOUT` | true | 整段超时 |
| `UPSTREAM_ERROR` | true | 上游模型异常 |
| `STREAM_INTERRUPTED` | true | 中途断流 |
| `CLIENT_CANCELLED` | false | 用户停止 |
| `SESSION_BUSY` | false | 会话已有进行中请求 |
| `DUPLICATE_IN_FLIGHT` | false | 相同 request_id 进行中 |
