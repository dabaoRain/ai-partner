# V1.0.7 伴侣评价与反馈体系优化

> 去掉每条 AI 回复下方常驻点赞/点踩，并将用户侧“人设”口径统一为“伴侣”，建立更符合智能伴侣关系线的分层评价体系。

## 产品判断

智能伴侣产品不适合在每条回复下面常驻点赞/点踩。常驻反馈按钮会让聊天像客服质检，削弱陪伴感，也会制造重复视觉噪音。

本版将反馈拆成三层：

1. **单条回复反馈**：隐藏在 AI 消息的 `...` 菜单里。
2. **本次聊天评价**：放在左侧伴侣三点菜单中，针对整场聊天体验。
3. **伴侣评价**：放在官方伴侣详情弹层中，针对伴侣资产本身。

用户侧不再使用“人设”作为主文案。“人设”是产品与工程内部概念，前台应表达为“伴侣”，避免让智能伴侣产品显得像 Prompt 配置工具。

## 交互原则

1. **不常驻展示点赞/点踩**  
   AI 回复下方不再固定显示点赞/点踩按钮。

2. **AI 消息 hover 显示更多菜单**  
   用户 hover 到 AI 回复气泡时，右上角出现一个小 `...`。

3. **消息菜单提供具体动作**  
   菜单包含：
   - `重新生成`
   - `反馈这条回复`
   - `复制`

4. **单条反馈要有原因**  
   点击 `反馈这条回复` 后弹出输入框，让用户描述具体问题，而不是只点踩。

5. **整场评价放到伴侣菜单**  
   左侧「我的伴侣」列表项的三点菜单新增 `评价本次聊天`。

6. **伴侣资产评价独立存储**  
   `评价伴侣` 用于衡量这位伴侣是否值得继续优化或保留，不与单条回复反馈、本次聊天评价混用。

7. **用户侧统一伴侣口径**  
   伴侣库弹层中面向用户的标题、按钮、空态、错误提示统一使用“伴侣”，不再使用“人设”。

## 本版改动

### 消息区

- 移除每条 AI 回复下方常驻点赞/点踩按钮。
- AI 回复气泡 hover/focus 时显示 `...` 菜单。
- `重新生成` 仅在最后一条可重试上下文中展示。
- `反馈这条回复` 复用消息反馈接口，默认记录为负向反馈，并附带用户填写的原因。
- `复制` 调用浏览器剪贴板能力。

### 左侧伴侣菜单

- 新增 `评价本次聊天`。
- 提交后通过埋点事件 `session_feedback` 上报：
  - `session_id`
  - `persona_id`
  - `persona_name`
  - `note`

### 官方伴侣弹层

- 弹层标题从 `官方人设` 改为 `官方伴侣`。
- 左侧列表标题从 `人设库` 改为 `伴侣库`。
- 空态从 `暂无官方人设` 改为 `暂无官方伴侣`。
- 未选中提示从 `请选择左侧人设查看详情` 改为 `请选择左侧伴侣查看详情`。
- 底部按钮从 `评价人设` 改为 `评价伴侣`。
- 加载失败提示从 `加载人设失败` 改为 `加载伴侣失败`。
- 评价弹层中的说明从“人设是否值得优化/保留”改为“这位伴侣是否值得优化/保留”。

### 伴侣评价

- 新增 `评价伴侣` 弹层。
- 使用 Element Plus `el-rate` 五星评分组件：
  - 最低 1 分
  - 最高 5 分
  - 文案为 `很差 / 较差 / 一般 / 不错 / 很好`
- 支持填写备注信息，最多 500 字。
- 备注建议围绕性格、语气、陪伴感、地域特色等维度填写。
- 已评价过的伴侣再次打开评价弹层时回显当前用户/游客自己的评分与备注。
- 伴侣评分不常驻展示在伴侣列表中，避免用户选择前被全站分数强暗示。

### 数据与接口

- 新增 `persona_ratings` 数据表，围绕 `persona_id` 存储伴侣评分与备注。
- 同一用户/游客对同一伴侣只保留一条评价：
  - 唯一口径：`owner_type + owner_id + persona_id`
  - 重复提交时更新原记录
- 新增 `GET /personas/{persona_id}/rating`：读取当前用户/游客对该伴侣的评价。
- 新增 `POST /personas/{persona_id}/rating`：提交或更新该伴侣评价。
- 新增 `persona_rating` 埋点事件。

## 后续建议

1. 单条反馈原因可升级为标签选择：
   - 不符合人设
   - 没理解我的意思
   - 太啰嗦
   - 情绪支持不好
   - 内容不安全/冒犯
   - 事实不准确
2. 本次聊天评价可升级为情绪评分：`很好 / 一般 / 不好`。
3. 可结合隐式行为信号：停止生成、重新生成、连续纠错、快速离开等。
4. 后续可新增运营统计视图：
   - 平均分最高伴侣
   - 平均分最低伴侣
   - 评分人数
   - 低分备注聚合
   - 伴侣优化/下线建议
5. 普通用户侧建议只展示自己的评分，不直接展示全站平均分。
