# V1.0.5 伴侣关系线模型

> 从「ChatGPT 多会话」收口为「一人设一条关系线」的陪伴交互。

## 产品原则

1. **侧栏「我的伴侣」** = 已聊过的人（每人设至多一条对话）。
2. **选择伴侣** = 选人：有线则打开，无线则进入空态。
3. **主按钮情境文案**  
   - 未选人设：`请先选择伴侣`（打开人设库）  
   - 无线：`开始聊天`  
   - 有线未打开：`打开对话`  
   - 当前正打开：`重置对话`（确认后清空重开）
4. **删除对话** = 结束该关系线；保留当前人设选择，可再次「开始聊天」。
5. **无对话冷启动**不预选默认人设（含赵一宁）；须手动「选择伴侣」。有历史时再登默认打开**最近更新**的一条。
6. **空态发送第一条消息** = 与「开始聊天」等价（幂等建线）；未选人设时引导先选人。

## 后端

- `POST /sessions` 支持 `persona_id` + `reset`  
  - `reset=false`（默认）：已有同人设会话则**复用**（`reused=true`）  
  - `reset=true`：删除旧线后重建  
- 列表按 `updated_at` 倒序。

## UI 文案

| 项 | 说明 |
| --- | --- |
| 侧栏主按钮 | 请先选择伴侣 / 开始聊天 / 打开对话 / 重置对话 |
| 列表区 | 「我的伴侣」；项名为人设姓名 |
| 人设入口 | 「选择伴侣」；未选时摘要为「点击选择一位伴侣」 |
| 主区空态 | 未选人：引导选伴侣；已选人：引导开始聊天或直接输入 |
| 输入框 placeholder | `想跟我说点什么…` |
| 侧栏标题 | `AI智能伴侣` |
| 隐私与账号菜单 | 暗色 hover/focus 修复 |

## 更新记录

### 2026-08-11 · 关系线模型首版

- 侧栏从「历史会话 / 新建会话」改为「我的伴侣」+ 情境主按钮（开始 / 打开 / 重置）。
- 选择伴侣：有线直接打开，无线仅选定不建线。
- 删除当前对话后保留人设，不自动跳到其他人设。
- 后端会话创建幂等复用；`reset` 重建；列表按最近更新排序。
- 主区去掉重复「开始聊天」按钮；开场白即锁定人设，禁止原地改会话人设。

### 2026-08-11 · 冷启动不预选人设

- 无对话进入时不再自动选中默认人设（赵一宁），须手动「选择伴侣」。
- 未选人设时主按钮为「请先选择伴侣」，点击打开人设库；发送消息同样先引导选人。
- 有历史对话再次进入：仍打开最近一条，人设来自该对话快照。
- 空态 / 侧栏摘要文案区分「未选人」与「已选人未开聊」。
