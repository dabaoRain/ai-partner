# V1.0.4 官方只读人设库

> 对应 [`plan.md`](../plan.md) P1「结构化基础人设」；人设内容来自 [`persona/index.md`](../persona/index.md)。

## 产品规则

- 官方人设**只读**：浏览、选择、应用到会话；不可编辑/删除。
- 默认人设为库中 `sort_order` 第一位（赵一宁）。
- 会话创建时写入**完整人设快照**；空会话可换人设；有问答后锁定。
- 新建会话会从 `openings` 随机选一条，作为助手开场白主动发出；仅有开场白、尚无用户发言时可换人设（会刷新开场白）。
- `easter_eggs`（彩蛋触发）已入库：`personas.easter_eggs` 与会话快照同字段，JSON `[{trigger, response}]`，并写入 system prompt。

## 字段（库表 `personas` / 会话快照对齐）

| 字段 | 说明 |
| --- | --- |
| `id` | 官方稳定 id（如 `official_ne_zhaoyining`） |
| `region` / `metaphor` / `age` / `avatar_url` / `status` / `sort_order` | 地区、隐喻、年龄（25～28）、美图路径、状态、排序 |
| `name` / `identity` / `tone` | 名字、身份、语气 |
| `catchphrases` | 口头禅（JSON 数组） |
| `interests` | 兴趣爱好（多行文本） |
| `intimacy_stages` | 亲密阶段（JSON：title/period/description） |
| `relationship_boundary` / `taboos` | 关系硬边界、禁忌 |
| `personality` | 补充性格 |
| `openings` / `easter_eggs` | 开场白、彩蛋触发（JSON） |

系统提示词优先级：**禁忌 > 关系硬边界 > 亲密阶段 > 身份 > 语气/兴趣/口头禅 > 补充性格**。

## API

- `GET /personas` 列表
- `GET /personas/default` 默认人设
- `GET /personas/{id}` 详情
- `POST /sessions` 可带 `persona_id`（缺省用默认）
- `PUT /sessions/{id}/persona` 空会话换人设（body: `{ persona_id }`）

## 初始化

启动时 `init_db()` 会 upsert `persona/index.md`。  
整库清空重建：`python -c "from db import init_db; init_db(reset=True)"`（在 `back/` 目录）。
