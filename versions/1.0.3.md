# V1.0.3 隐私与用户控制 V1 + 埋点与质量看板

> 对应 [`plan.md`](../plan.md) P0 第 93–94 行

## 隐私与用户控制 V1

| 能力 | 落地 |
| --- | --- |
| 明示收集目的 | 登录门禁勾选/展示；`GET /privacy/policy` |
| 会话删除 | 已有 `DELETE /sessions/{id}` |
| 账号注销 | `DELETE /auth/account`（校验密码，级联清数据） |
| 记忆开关预留 | `GET/PATCH /privacy/preferences.memory_enabled`（仅存储，无记忆引擎） |
| 数据保留策略 | 策略文案 + 配置天数；`POST /privacy/purge-expired` 清理过期游客等 |
| 权限可审计 | `permission_logs`：注册同意、记忆开关、注销等 |
